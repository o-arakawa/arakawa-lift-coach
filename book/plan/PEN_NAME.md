# ペンネーム選定（画数＝姓名判断・五格剖象法／数秘術）

**決定: 荒川 知哉（あらかわ ともや／Arakawa Tomoya）**

姓「荒川」はブランド（GitHub・サイト名）と本名のまま残し、名を画数と数秘で選び直した。姓ごと変えたい場合は同じ手順で再計算できる（`book/build/pen_name_score.py`）。

## 1. 前提（Web調査で確認した計算ルール）

- 「荒」は新字体9画（主要な無料サイト namaeuranai.biz／enamae.net／seimei-handan.com／mnamae.jp の既定）、康熙字典体では艸＝6画で12画。「川」は3画。本書では**両方の数え方で全格が吉になる名**だけを採用した。
- 五格（熊崎式）: 天格＝姓の合計、人格＝姓の下の字＋名の上の字、地格＝名の合計、外格＝姓の上の字＋名の下の字、総格＝全部。一字名は霊数1を地格・外格に加える（総格には加えない）。
- 天格は姓で固定（新12画＝凶／旧15画＝大吉）のため評価対象外。吉凶は人格・総格を最重視し、地格・外格も凶を避ける。
- **一字名は不可**: 新字体では外格＝荒9＋霊数1＝10画（大凶）に固定されるため、二字名に限定した。
- 数秘術: ピタゴラス式の表現数（姓名のローマ字 A=1…I=9, J=1…）。生年月日が未提供のためライフパスナンバーは使わず、個別還元法（姓・名を別々に還元して合算）と一括法の両方で確認した。
- 名の漢字は、新字体と康熙字典体で画数が変わらない字（さんずい・くさかんむり・しんにょう・こざとへん・りっしんべん・てへん等を含まない）だけを使った。

## 2. 五格がすべて吉になる二字名の条件（荒川の場合）

名の上の字 c と下の字 d の画数が、新字体・康熙の両方で 人格(3+c)・地格(c+d)・外格(9+d／12+d)・総格(12+c+d／15+c+d) のすべてを吉数にする組み合わせは、実用的な範囲では **c+d＝17（c=5,d=12／c=8,d=9／c=13,d=4）** に限られる。候補はこの3パターンから作った。

## 4. 決定理由

- **知哉（ともや）**: 人格11（再興・順調発展。穏やかな繁栄）、地格17（剛健・突破力。強気で押し切る（流派差あり））、外格18／21、総格29／32（僥倖・引き立て運。幸運が舞い込む）。数秘は個別法・一括法とも **1**（先駆者・リーダー。独立心、自発性、開拓、「自分で始める」力。孤立や独善に注意。…）。「知」は本書の商品そのもの（頭の中を話して渡す）、「哉」は語りかける文体に合う。読みやすく、検索で有名人と強く被らない。20代後半の読者に近い世代感の名前。
- 次点: **正貴（まさき）**＝数秘11（発信者向き）、**正翔（まさと）**＝数秘8（事業・収益向き）。落ち着いた印象が欲しければ正貴、販売動線を強く意識するなら正翔。
- 三才配置（天格・人格・地格の五行）まで見ると、康熙字典体では 義文・新太・雅仁・靖介（土-土-金）が最も整うが、読みの自然さと数秘を優先して知哉を採った。
